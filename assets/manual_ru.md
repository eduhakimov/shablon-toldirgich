# Заполнение заявлений и шаблонов: руководство

## 1. Создайте профиль
В разделе **Профили** нажмите **Добавить** и введите данные: ФИО, дату рождения, адрес, телефон, паспорт,
ПИНФЛ, место работы, должность и т.д. Для членов семьи создайте отдельные профили. Нажмите **Сохранить**.

Паспорт и ПИНФЛ скрыты. Чтобы их увидеть, включите **Показать скрытые данные**.

**Защита паролем**: профили шифруются (AES). При следующем запуске раздел «Профили» запросит пароль.
Забытый пароль восстановить нельзя.

## 2. Подготовка документа
1. В разделе **Подготовка документа** выберите шаблон слева (или **Открыть другой .docx**).
2. В списке **Для кого** выберите профиль. Подходящие поля заполнятся автоматически.
3. Заполните пустые (выделенные цветом) строки, например даты отпуска.
4. Проверьте результат на вкладке **Просмотр**.
5. Укажите папку и имя файла, при необходимости включите **Также создать PDF**.
6. Нажмите **Создать документ**.

В имени файла `{QISQA_FISH}`, `{FISH}`, `{SANA}` заменяются значениями. Файл шаблона не изменяется.

## 3. Свой шаблон
Напишите документ в Word и в изменяемых местах поставьте `{{ИМЯ}}`:

| Поле | Что подставляется |
|---|---|
| `{{FISH}}` | Фамилия Имя Отчество |
| `{{QISQA_FISH}}` | A.R. Karimov |
| `{{SANA}}` | сегодняшняя дата, 27.11.2026 |
| `{{SANA_SOZ}}` | 2026-yil 27-noyabr |
| `{{MANZIL}}`, `{{TELEFON}}`, `{{PASPORT}}`, `{{JSHSHIR}}` | из профиля |
| `{{TASHKILOT}}`, `{{BOLIM}}`, `{{LAVOZIM}}`, `{{GURUH}}` | из профиля |
| `{{RAHBAR_LAVOZIM}}`, `{{RAHBAR_FISH}}` | кому адресовано |

Имена не из списка (например `{{KURS}}`) запрашиваются при заполнении и запоминаются. Оформление
(шрифт, жирный, таблицы, колонтитулы) сохраняется. Добавьте файл в библиотеку в разделе **Шаблоны**.

## 4. Пакетно из Excel
1. В первой строке Excel укажите названия столбцов: Familiya, Ism, Otasining ismi, Guruh...
2. В разделе **Пакетно из Excel** выберите шаблон и файл.
3. Проверьте **Сопоставление**. Общее для всех строк значение впишите в **Постоянное значение**.
4. Нажмите **Создать документы**: для каждой строки создаётся отдельный .docx (и PDF).

## PDF
PDF создаётся через Microsoft Word. Если Word не установлен, используется LibreOffice.
